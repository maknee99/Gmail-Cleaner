📧 GmailCleaner

GmailCleaner es una herramienta sencilla para eliminar correos no deseados de tu cuenta de Gmail con unos pocos clics.

📂 Descarga y Ejecución

1️⃣ Descargar la Carpeta

Descarga el repositorio o la carpeta GmailCleaner que contiene GmailCleaner.exe.

Asegúrate de que el archivo credentials.json esté en la misma carpeta (ver sección Obtener credenciales).

2️⃣ Ejecutar el Programa

Doble clic en GmailCleaner.exe para abrirlo.

Inicia sesión en Google cuando se solicite.

Selecciona los filtros de los correos que quieres eliminar.

Confirma la eliminación y deja que la herramienta haga su trabajo.

🔑 Obtener credenciales de Google (credentials.json)

Para que la aplicación funcione, necesitas generar tu propio archivo credentials.json.

1️⃣ Ir a la Consola de Google

Abre Google Cloud Console.

Crea un nuevo proyecto o selecciona uno existente.

Habilita la API de Gmail.

2️⃣ Crear credenciales

Ve a Credenciales y haz clic en Crear credenciales > ID de cliente OAuth.

Selecciona Aplicación de escritorio y ponle un nombre (ej. "GmailCleaner").

Descarga el archivo credentials.json.

3️⃣ Colocar credentials.json

Guarda el archivo credentials.json en la misma carpeta que GmailCleaner.exe.

Ejecuta el programa y sigue las instrucciones para iniciar sesión en Google.

🚨 IMPORTANTE: No compartas tu credentials.json, ya que contiene tu clave personal.

⚠️ Requisitos

Windows 10 o superior.

Conexión a Internet.

Se recomienda ejecutar como administrador si hay problemas.

📌 Notas

Si Google bloquea el acceso, revisa la configuración de seguridad de tu cuenta.

Si el antivirus detecta el .exe como sospechoso, agrégalo a la lista de exclusiones.
