OBTENER CREDENCIALES DE GOOGLE (credentials.json)
Para usar esta herramienta, necesitas generar tu propio archivo credentials.json.

IR A LA CONSOLA DE GOOGLE

Abre Google Cloud Console: https://console.cloud.google.com/
Crea un nuevo proyecto o selecciona uno existente.
Habilita la API de Gmail.
CREAR CREDENCIALES

Ve a "Credenciales" y haz clic en "Crear credenciales" > "ID de cliente OAuth".
Selecciona "Aplicación de escritorio" y ponle un nombre (ej. "GmailCleaner").
Descarga el archivo credentials.json.
COLOCAR credentials.json

Guarda el archivo credentials.json en la misma carpeta que GmailCleaner.exe.
Ejecuta el programa y sigue las instrucciones para iniciar sesión en Google.
IMPORTANTE: No compartas tu archivo credentials.json, ya que contiene tu clave personal.

USO

Ejecuta GmailCleaner.exe.
Inicia sesión en Google.
Selecciona los filtros y elimina los correos no deseados.
REQUISITOS

Windows 10 o superior.
Conexión a Internet.
Se recomienda ejecutar como administrador si hay problemas.
NOTAS

Si Google bloquea el acceso, revisa la configuración de seguridad de tu cuenta.
Si el antivirus detecta el .exe como sospechoso, agrégalo a la lista de exclusiones.
